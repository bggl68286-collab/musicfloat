# 帝国鹰首军剑 · Minecraft 1.20.1 Forge

以拿破仑时期鹰首军剑参考图为基础的三维武器模组。包含金色剑气、旋转法阵、鹰徽爆发与持剑动作，默认按偏无双的高伤害玩法配置。

## 安装

1. 使用 Minecraft **1.20.1** 和 **Forge 47.3.22 或更新的 47.x**，运行环境为 Java 17。
2. 把 `imperial_sabre-1.0.0.jar` 放进该游戏实例的 `mods` 文件夹。不要解压 JAR。
3. 启动游戏，在创造模式“战斗”分类找到“帝国鹰首军剑”。
4. 联机时，客户端和服务器都需要安装相同版本。无需 GeckoLib 或其他动画依赖。

也可以使用命令：

```mcfunction
/give @p imperial_sabre:eagle_sabre
```

## 操作与默认属性

| 操作 | 效果 |
| --- | --- |
| 左键挥砍 | 斩击与回收动作、金色剑弧、火花；基础总攻击伤害 28，攻击速度 1.8 |
| 短按右键后松开 | 18 格前方锥形黄金剑气，36 伤害，3 秒冷却 |
| 按住右键至少 1 秒后松开 | 举剑蓄力、旋转法阵，释放鹰徽与金色冲击环；半径 12 格，90 伤害，8 秒冷却 |
| 未攻击时 | 第一人称呼吸摆动，第三人称持剑姿势 |

技能命中会击退目标并消耗 3 点耐久。伤害、范围和冷却由服务器判定。范围技能尊重视线与队友关系，默认不伤害其他玩家；普通近战仍遵循服务器 PvP 规则。技能不会破坏方块。

在 3×3 工作台中合成，`N` 为下界合金锭、`G` 为金锭、`S` 为下界合金剑、`B` 为烈焰棒：

```text
空 N G
空 S G
B 空 空
```

## 调整

进入世界后，服务器配置位于该世界的 `serverconfig/imperial_sabre-server.toml`。可调整 `waveDamage`、`novaDamage`、`waveRange`、`novaRadius`、冷却时间及范围技能 PvP。

“最少/较少粒子”设置会减少附加火花；主要剑气、鹰徽与法阵仍可见。特效通过全亮粒子渲染发光，不需要光影包，也不会真的照亮附近方块。

动作覆盖军剑的第一人称持剑、挥斩、回收、蓄力和释放，以及第三人称手臂持剑/蓄力姿势。没有新增玩家全身骨骼、翻滚或跳跃动画。

## 美术资源

军剑网格来自本次制作的 `.bbmodel`，由 `tools/export_assets.py` 转为 Forge OBJ。特效使用生图工具制作的 2×2 透明图集：左上剑气、右上爆发、左下鹰徽、右下法阵。程序按象限 UV 采样；原始生图未重绘、未裁切。

## 从源码构建

安装 Java 17，在项目目录运行：

```powershell
.\gradlew.bat build
```

Linux/macOS：

```sh
chmod +x gradlew
./gradlew build
```

输出位于 `build/libs/imperial_sabre-1.0.0.jar`。需要允许访问 Forge、Minecraft、Maven Central 和 Gradle 官方下载服务。

运行自动游戏测试：`./gradlew runGameTestServer`。测试验证服务器加载、剑气方向边界、网络序列化，以及蓄力技能伤害/冷却/耐久消耗。

运行开发客户端：`./gradlew runClient`。图形检查需要可用的 OpenGL 显示环境。
