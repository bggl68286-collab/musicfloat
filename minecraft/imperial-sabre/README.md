[中文安装和操作说明](README_中文.md) · [验证记录](VALIDATION.md)

左键挥砍；短按右键释放剑气；按住右键至少 1 秒后松开，释放鹰徽与金色冲击环。默认技能伤害较高，范围技能不伤害玩家，参数可在世界的服务器配置中调整。
