# 格里博瓦尔手持大炮 · Minecraft 1.20.1 Forge

以拿破仑时期法国格里博瓦尔 12 磅野战加农炮参考图为基础，制作可在 Blockbench 编辑的精细网格，再适配为双手托持的游戏武器。青铜炮管、绿木炮架、铁箍辐条轮、炮耳、提把、炮尾、链条及双头海绵杆均有独立几何结构。

## 安装

1. Minecraft **1.20.1**、**Forge 47.3.22 或更新的 47.x**、**Java 17**。
2. 将 `napoleonic_cannon-1.0.0.jar` 放入游戏实例的 `mods` 文件夹，无需解压。
3. 创造模式“战斗”分类中有大炮、实心弹和霰弹罐。
4. 联机时客户端与服务器均安装相同版本。无需 GeckoLib，可与之前的军剑模组一同安装。

```mcfunction
/give @p napoleonic_cannon:hand_cannon
/give @p napoleonic_cannon:round_shot 64
/give @p napoleonic_cannon:canister_shot 64
/give @p minecraft:gunpowder 64
```

## 使用

大炮放在**主手**，全程作为手持物品使用。副手物品仍在背包中，托炮时暂时隐藏副手物品画面。

| 操作 | 效果 |
| --- | --- |
| 按住右键 5.8 秒 | 清膛 → 装入火药包 → 装入炮弹 → 翻转装填杆推弹 → 调整瞄准 |
| 装填完成后继续按住 | 双手托稳、瞄准；装填进度条显示准备完毕 |
| 松开右键 | 引火燃烧，约 0.35 秒后开炮；火焰、白烟、火星、炮响与后坐同步 |
| 开炮后 | 炮管后坐、轮辐转动，随后炮架复位；可开始下一次装填 |
| 装填途中松手 | 取消本轮装填，不消耗弹药 |
| 蹲下 + 右键 | 未装填时切换实心弹／霰弹；已装填时锁定膛内弹种 |
| 引火时切换物品 | 取消点火，保留膛内炮弹 |

生存模式每次完整装填消耗 **1 份原版火药 + 1 发选定炮弹**。发射消耗 2 点大炮耐久。创造模式无需弹药。大炮必须放在主手。

实心弹默认 78 伤害；霰弹为 14 颗散布弹丸，每颗 8 伤害，适合近距离。炮弹有重力、飞行时间和墙壁碰撞。默认保护射手、队友和其他玩家，不破坏地形。声音、伤害、弹丸数及速度可在世界的 `serverconfig/napoleonic_cannon-server.toml` 中调整。

## 合成

大炮工作台排列：

```text
铜块 铜块 铜块
铁块 下界合金锭 铁块
原木 空 原木
```

3 个铁锭无序合成 8 发实心弹；1 个铁锭 + 1 发实心弹无序合成 2 发霰弹罐。

## 模型、动作与美术

`art/source/gribeauval_12pdr.bbmodel` 已在 Blockbench 5.2.1 打开、检查并保存，内嵌 1024×1024 材质，可编辑全部 144 个网格、9 个部件分组和 3 条基础动作。默认隐藏装填工具与弹药辅助网格；在 Blockbench 中展开相应分组并开启网格显示即可检查。游戏使用相同几何和 UV，并在运行时组合完整装填、双手姿态、瞄准、点火、后坐和复位。

`art/source/cannon_fx.png` 为生图工具制作的透明 2×2 写实特效图集：炮口火焰、黑火药白烟、引火火星、命中尘土。游戏按象限 UV 采样，原始生成图未裁切或重绘。火焰与火星全亮，烟尘受环境光影响。烟雾会扩散、上升并消散；附加粒子随游戏粒子设置减少。

声音按你的选择只有装填与炮声，没有人声口令。9 条原创合成音包含清膛摩擦、火药包、铁弹入膛、推弹撞击、炮架吱响、引火、炮响、复位和命中，并提供中英字幕。`art/audio` 保存无损 WAV，游戏使用单声道 OGG Vorbis。炮声采用低频、瞬态、气浪与回声分层合成，并非实地录音。

## 源码构建

Java 17 下运行 `gradlew.bat build`（Windows），或 `chmod +x gradlew && ./gradlew build`（Linux/macOS）。成品位于 `build/libs`。

`./gradlew runGameTestServer` 运行实际服务器游戏测试；`./gradlew runClient` 启动开发客户端。美术重建需要 Python 的 numpy、Pillow、scipy 以及 ffmpeg：`python tools/make_model.py`、`python tools/make_audio.py`。

历史野战炮在游戏中缩放为可携带武器；动画覆盖物品各部件、第一人称双手和第三人称手臂。材质使用标准 Forge 渲染，可通过玩家自己的光影包进一步增强照明。
